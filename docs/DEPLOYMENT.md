Состояние на 3 ноября 2026 года.

## Опубликовано

- Сайт: https://edu-safe-alpha.vercel.app/
- Демо: https://edu-safe-alpha.vercel.app/demo
- GitHub: https://github.com/Ibrahim200546/EduSafe
- Vercel: проект `edu-safe`, команда `ibrahims-projects-cde59db2`, подключена ветка `main`.
- Supabase: отдельный проект `EduSafe`, ref `dinubypuzjrvgtcvrkwe`, регион Frankfurt (`eu-central-1`).
- Миграции 001–007 применены. Приложение использует Supabase Auth и PostgreSQL, а не демонстрационную память сервера.
- В Vercel для Production заданы URL Supabase и publishable key. Service role в Vercel не передаётся.
- Edge Functions `notification-worker` и `telegram-webhook` активны. Их запросы защищены собственными секретами; запрос без секрета проверенно получает HTTP 401.
- Задачи `edusafe-attendance-and-escalation` и `edusafe-notification-worker` запускаются раз в минуту. HTTP-запуск worker через `pg_net` проверен: 200, без ошибки или таймаута.
- URL проекта и случайный секрет обработчика хранятся в Vault; в исходниках и документации секретов нет.

## Настройка писем — ещё требуется

Парольный вход и сессии уже проверены на опубликованном сайте. Для регистрации с подтверждением почты и восстановления пароля нужно завершить настройку **Authentication → URL Configuration** в панели Supabase:

- Site URL: `https://edu-safe-alpha.vercel.app`.
- Redirect URLs: `https://edu-safe-alpha.vercel.app/auth/callback**`. Суффикс нужен для параметра `next`; разрешается только callback на этом конкретном домене.
- Проверить шаблоны писем и доставку через выбранный SMTP. Для пилота с приглашением сотрудников/родителей проверить письма на согласованных тестовых получателях.

В этой сессии вход в панель Supabase остановился на интерактивной CAPTCHA. Поэтому сохранение этих URL и реальная доставка писем **не заявляются выполненными**. Проверку подтверждения email отключать не требуется.

Справка: https://supabase.com/docs/guides/auth/redirect-urls

После настройки: откройте `/login`, создайте аккаунт, подтвердите почту, затем создайте свою организацию. Можно добавить учебный набор данных. Доступ к существующей организации выдаётся приглашением администратора.

## Перенос в другой проект

Миграция 007 читает адрес назначения из Vault, без жёстко записанного project ref. В новой среде необходимо создать `edusafe_project_url`, случайный `edusafe_worker_secret` и зарегистрировать хеш последнего через служебную `edusafe_set_integration_secret('worker', ...)`. Только после этого задача HTTP начнёт вызывать Edge Function.

Код содержит отдельные учебные данные для публичного демо. Реальных данных учащихся при разработке не использовалось. Временная HTTP-тестовая организация и аккаунт удалены после успешной проверки.
