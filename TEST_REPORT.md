# EduSafe — фактические проверки

Дата: 3 ноября 2026. Проверки выполняются на отдельном проекте EduSafe в Supabase, с вымышленными данными и без реальных сообщений Telegram.

## Выполнено

| Проверка | Результат |
|---|---|
| TypeScript всего Next.js-приложения | Успешно, `tsc --noEmit` |
| Production-сборка | Успешно, `npm run build`, Next.js 16.4.4 |
| Защитные утилиты | 4 теста: безопасный redirect, Origin, QR URL, CSV |
| Worker и webhook | 24 теста с подставными HTTP/RPC; повторные запросы, ошибки доставки, секреты и права |
| Deno types | Оба Edge entrypoint проходят `deno check` |
| SQL и PL/pgSQL parse | Пять основных миграций и интеграционный сценарий проходят pglast |
| Реальная PostgreSQL/Supabase | 53 утверждения в `tests/database_integration.sql`, все успешны; транзакция откатилась |
| Production dependencies audit | 0 известных уязвимостей на момент проверки, `npm audit --omit=dev` |
| Развёртывание БД | Миграции схемы, авторизации, доменных действий и worker применены |
| Edge Functions | `notification-worker` и `telegram-webhook` развёрнуты, статус ACTIVE |

SQL-сценарий проверяет QR для двадцати учеников, повторную отметку, истёкший и поддельный код, неизменность подтверждения преподавателя, изоляцию школ, доступ только к связанным детям, запрет отметки родителем, отзыв полномочий преподавателя, блокировку аккаунта и отзыв веб-сессии. Отдельно проверены идемпотентная регистрация тревоги, принятие и закрытие, история, дедупликация очереди, аренды worker и отозванный доступ получателя перед отправкой.

## Границы результатов

- Тесты обработчиков используют подставной Telegram API. Реальный бот, доставка на телефон и получение сотрудником не проверены.
- Публичное демо использует только локальные вымышленные данные. Оно не является проверкой сохранения в Supabase.
- Production URL, визуальная проверка браузером, настройки Auth callback и сквозной HTTP-сценарий фиксируются ниже по завершении публикации.
- Нагрузочный тест, восстановление резервной копии и эксплуатационный пилот в школе не проводились.
- Интерфейс RU/KK переведён для основных разделов, статусов и действий; часть подробных пояснений пока на русском.

## Воспроизведение

```bash
npm ci
npm run typecheck
npm test
node --experimental-strip-types --test supabase/functions/_shared/worker.test.ts
npm run build
```

SQL-тест запускается администратором **только в отдельной тестовой Supabase-базе** после миграций. Он использует `BEGIN … ROLLBACK`, временные фиктивные Auth-записи и смену PostgreSQL-ролей. Это не команда для выполнения через браузерный publishable key.
